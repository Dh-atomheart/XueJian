# 学笺项目状态总览

## 项目概览

### 基本信息
- **项目名称**: 学笺 (XueJian)
- **项目定位**: 本地优先的桌面学习应用
- **核心价值**: 围绕"资料导入 → 阅读加工 → 卡片生成 → 间隔复习 → 知识问答/图谱 → 播客生成"构建完整学习闭环
- **当前版本**: v0.1.0 (开发中)
- **许可证**: GPL v3
- **开发语言**: TypeScript, Rust, Python
- **项目地址**: e:\XueJianProject

### 项目愿景
学笺致力于成为AI驱动的智能学习记忆应用，通过本地优先的设计理念，为用户提供私密、高效、个性化的学习体验。应用整合了文档处理、知识管理、间隔复习、AI问答等多种学习工具，形成完整的学习生态系统。

## 技术架构

### 整体架构设计
```
┌─────────────────────────────────────────────────────────┐
│                    前端层 (React)                        │
├─────────────────────────────────────────────────────────┤

├─────────────────────────────────────────────────────────┤

├─────────────────────────────────────────────────────────┤
```

### 前端技术栈
- **核心框架**: React 19.0.0
- **开发语言**: TypeScript 5.8.0
- **构建工具**: Vite 6.0.0
- **样式系统**: TailwindCSS 3.4.0 + PostCSS
- **状态管理**: Zustand 5.0.0 + TanStack Query 5.0.0
- **UI组件库**: Radix UI + Lucide React 1.9.0
- **动画引擎**: Framer Motion 12.38.0
- **路由系统**: React Router (内置)
- **数据验证**: Zod 3.25.76

### 桌面框架 (Tauri)
- **版本**: Tauri 2.0.0
- **后端语言**: Rust 1.77.2
- **数据库**: SQLite (rusqlite 0.32) + 向量扩展 (sqlite-vec 0.1.9)
- **安全存储**: Tauri Stronghold + iota_stronghold 2.1.0
- **文件系统**: Tauri Dialog + Shell 插件
- **异步运行时**: Tokio 1.0
- **HTTP客户端**: reqwest 0.12

### AI编排服务 (Python)
- **核心框架**: LangChain 0.3.x + FastAPI
- **AI提供商**: 
  - OpenAI (openai >= 1.51)
  - Anthropic (langchain-anthropic >= 0.3)
  - Google (langchain-google-genai >= 2.0)
  - 通用接口 (litellm >= 1.40)
- **文档处理**: 
  - docling >= 2.0 (文档解析)
  - pymupdf >= 1.24 (PDF处理)
- **语音合成**: 
  - edge-tts >= 6.1 (微软TTS)
  - elevenlabs >= 1.8 (ElevenLabs)
  - fish-audio-sdk >= 2024.12.0
- **音频处理**: pydub >= 0.25
- **数据验证**: Pydantic 2.0 + Pydantic-AI 0.1

### 数据存储架构
- **主数据库**: SQLite (本地优先)
- **向量存储**: SQLite + sqlite-vec 扩展
- **文件存储**: 本地文件系统
- **缓存机制**: IndexedDB (浏览器) + 内存缓存
- **数据迁移**: Refinery 0.8

## 核心功能模块

### 1. 文档管理系统
**功能描述**: 支持多格式文档导入、解析、标注和阅读
**技术实现**:
- PDF处理: pdfjs-dist 5.6.205
- 文档渲染: 自定义PDF查看器 + 文本选择
- 标注系统: 高亮标注 + 便签功能
- 文档分析: AI驱动的内容提取和结构化

**主要组件**:
- `DocumentList`: 文档列表管理
- `PdfViewer`: PDF查看器组件
- `HighlightLayer`: 高亮标注层
- `StickyNotesPanel`: 便签面板
- `TextSelectionPopover`: 文本选择操作

### 2. 卡片工坊系统
**功能描述**: AI驱动的学习卡片生成、编辑和管理
**技术实现**:
- 卡片类型: 填空题、选择题、图片遮挡、问答题
- AI生成: 基于文档内容的智能卡片生成
- 动画效果: roughjs 4.6.6 + 自定义动画引擎
- 复习算法: ts-fsrs 4.1.0 (FSRS间隔重复算法)

**主要组件**:
- `CardStudioPage`: 卡片工坊主页面
- `CardCandidatePanel`: 候选卡片面板
- `CardEditorModal`: 卡片编辑器
- `AnimationRenderer`: 动画渲染器
- `CardContentRenderer`: 卡片内容渲染

### 3. 学习复习系统
**功能描述**: 基于FSRS算法的智能间隔复习系统
**技术实现**:
- 复习算法: FSRS (自由间隔重复系统)
- 学习统计: 学习数据追踪和可视化
- 进度管理: 复习进度和完成状态
- 成就系统: 学习热力图和积分台账

**主要组件**:
- `ReviewPage`: 复习页面
- `FlipCard`: 翻转卡片组件
- `RatingBar`: 评分条
- `SessionProgress`: 会话进度
- `StudyStatsCard`: 学习统计卡片

### 4. 知识问答系统
**功能描述**: 基于RAG的文档问答系统，支持引用追溯
**技术实现**:
- RAG架构: 检索增强生成
- 向量搜索: 文档内容向量化和相似度检索
- 引用管理: 答案来源追溯和跳转
- 范围筛选: 文档范围限制和上下文控制

**主要组件**:
- `KnowledgeQaPage`: 知识问答页面
- `KnowledgeChatPanel`: 聊天面板
- 答案渲染器: 支持Markdown和LaTeX
- 引用面板: 来源文档引用展示

### 5. 知识图谱系统
**功能描述**: 概念关系可视化和知识网络导航
**技术实现**:
- 图形渲染: sigma 3.0.2 + graphology 0.26.0
- 布局算法: forceatlas2 力导向布局
- 交互设计: 节点拖拽、缩放、搜索
- 数据关联: 概念提取和关系建立

**主要组件**:
- `KnowledgeGraphPage`: 知识图谱页面
- 图谱渲染器: 交互式图形显示
- 搜索面板: 概念搜索和过滤
- 详情面板: 节点信息展示

### 6. 播客工坊系统
**功能描述**: AI驱动的播客内容生成、合成和管理
**技术实现**:
- 内容生成: AI脚本生成和优化
- 语音合成: 多TTS引擎支持
- 音频处理: 音频剪辑和效果处理
- 播放管理: 播放器控制和播放列表

**主要组件**:
- `PodcastPage`: 播客工坊页面
- `PodcastPlayerModal`: 播放器模态框
- 脚本编辑器: 内容编辑和预览
- 音频处理: 合成和导出功能

### 7. 用户中心系统
**功能描述**: 个人学习概览、成就展示和设置管理
**技术实现**:
- 学习概览: 学习数据统计和可视化
- 热力图: 学习活跃度日历展示
- 积分系统: 学习成就和积分台账
- 设置管理: AI配置、学习偏好、系统设置

**主要组件**:
- `ProfilePage`: 个人主页
- `SettingsPage`: 设置页面
- `HomeHeatmapPanel`: 热力图面板
- `HomeStudyOverviewPanel`: 学习概览面板

## 工作流程设计

### 用户学习旅程
```
1. 新用户引导 → AI配置 → 首次导入
2. 文档导入 → 阅读标注 → 内容理解
3. 卡片生成 → 编辑审核 → 入库管理
4. 复习计划 → 间隔复习 → 学习跟踪
5. 知识问答 → 概念探索 → 深度理解
6. 知识图谱 → 关系发现 → 体系构建
7. 播客生成 → 内容巩固 → 多模态学习
```

### 数据流架构
```
文档输入 → 格式解析 → 内容提取 → 向量化 → AI处理
    ↓
卡片生成 → 题型设计 → 动画制作 → 复习调度 → 学习跟踪
    ↓
知识检索 → 问答生成 → 引用管理 → 图谱构建 → 关系发现
    ↓
内容整合 → 播客生成 → 语音合成 → 播放管理 → 学习闭环
```

### AI集成架构
```
用户请求 → 意图识别 → 提供商选择 → 模型调用 → 结果处理
    ↓
错误处理 → 降级策略 → 缓存管理 → 成本控制 → 质量评估
```
