# 学笺前端体验规范总览

## Summary

学笺前端采用“暖白极简、桌面优先、低噪音工作台”的统一体验语言。设计主参考为 `examples/sample of design code/b_UWqxn1dtBzw`，实现仍保留现有 Vite/React/Tauri 架构，不引入新的运行时。

## Design Principles

- 单壳层工作台：左侧主导航 + 顶部页面标题 + 主内容区 + 可选右侧上下文栏。
- 优先任务闭环：每个页面第一屏必须回答“现在做什么”和“下一步去哪”。
- 低噪音信息密度：减少装饰性视觉，强调结构、状态、可追踪任务。
- 真实数据优先：所有页面展示建立在现有查询层与网关层之上，不保留第二套 mock 业务状态。
- 桌面优先：大多数页面使用双栏或多区结构，移动端做减法而不是重新发明信息架构。

## Visual System

- 颜色：暖白背景、柔和边框、极浅卡片层级、温和绿色作为主要正向状态色。
- 组件：统一使用圆角卡片、胶囊按钮、轻边框输入框、弱阴影列表项。
- 标题层级：英文小眉题 + 中文主标题 + 一行描述。
- 反馈：空态、加载态、错误态与长任务状态都使用同一套卡片语言。
- Reader：保持专业阅读舞台，不与其他业务页面混淆。

## Information Architecture

顶层导航固定为：

1. 首页
2. 文档库
3. 卡片工坊
4. 学习
5. 知识问答
7. 播客工坊
8. 我的
9. 设置


## Implementation Boundaries

- `App.tsx` 继续按 `activeNavItem` 驱动页面切换。
- `store/ui.ts` 继续承担导航与 Reader 上下文状态。
- `queries/`、`services/gateway/` 继续作为真实数据入口。
- `data-testid` 属于验收接口，不随视觉重构任意改名。

## Documentation Rules

- 所有前端阶段文档统一使用这套设计语言，不再描述旧的手绘/纸感视觉体系。
- 页面文档以结构、状态、数据绑定和跳转关系为核心，不再围绕旧视觉 token 展开。
- 当参考设计与真实能力冲突时，以“真实可打通”优先，视觉尽量保持高保真。
