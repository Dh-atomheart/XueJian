# M11：学习仪表盘与体验打磨

## 目标

完成首页学习仪表盘、学习热力图、文档/分组进度和 UI 打磨，作为第一阶段整体体验 gate。

## 所属 MVP

MVP-2，第一阶段整体体验 gate。

## 相对工作量

M。

## 前置条件

- M10 完成。
- study_events 已稳定记录。

## 交付内容

- 首页展示今日完成数。
- 首页展示总学习时长。
- 首页展示连续学习天数。
- 首页展示学习热力图。
- 首页展示文档进度。
- 首页展示分组进度。
- Reader、复习页、统计图窄宽度不重叠。
- 主页面 empty/loading/failed 状态完整。

## 任务分配

### Frontend

- 首页 dashboard 面板。
- Heatmap 组件。
- 文档进度和分组进度卡片。
- UI 细节按 `docs/ui.md` 打磨。

### Rust/Tauri

- 查询今日完成数。
- 查询总学习时长。
- 查询连续学习天数。
- 查询 heatmap。
- 查询文档/分组进度。

### Python orchestration

- 无新增任务。

### Data/Schema

- 统计以 study_events 为事实来源。
- 如需缓存，缓存必须可重建。

### Tests

- 今日完成数。
- 总学习时长。
- 连续学习天数。
- heatmap 色阶。
- 文档/分组进度。
- UI 状态测试。

## 不做什么

- 不做复杂记忆模型预测。
- 不做 points。
- 不做云同步。
- 不做 RAG。
- 不做播客或动画。

## 验收场景

- 用户完成复习后首页今日完成数更新。
- 首页显示热力图、总学习时长、连续学习天数。
- 首页显示文档和分组进度。
- 所有 MVP 主页面有空、加载、失败状态。
- UI 不出现冻结入口。

## 测试要求

- 统计查询单元测试。
- 首页前端测试。
- 第一阶段 e2e smoke。

## 风险与回退

- 统计口径争议：以 study_events 为事实来源。
- UI 打磨范围膨胀：只修阻碍 MVP 体验和验收的问题。

## 完成后解锁

第一阶段主闭环完成。后续可按路线评估 RAG、播客脚本、TTS、导出或同步等扩展能力。
