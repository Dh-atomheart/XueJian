# 学习工作台（Study Bench）交互界面设计规范 v1.0

本文档是 [XueJian 前端设计与实施规范](./ui.md) 的执行级详细手册，用于指导后续 UI 改造、页面打磨和组件落地。`docs/ui.md` 保持权威总纲地位；本文档负责补充页面、组件、状态、主题和交互细节。

冲突处理：

- 产品边界、MVP 范围和阶段路线以 [spec.md](./spec.md) 为准。
- UI 权威边界和技术栈以 [ui.md](./ui.md) 为准。
- 本文档中的 `Proposal` 仅代表设计提案，未同步 `spec.md` 前不得作为开发验收依据。

## 1. 阶段标签

| 标签 | 含义 | 开发处理 |
|------|------|----------|
| `MVP` | 当前主线可实施范围 | 可直接进入开发和验收 |
| `V1` | 近期路线，依赖 MVP 基础稳定 | 可进入规划，实施前确认里程碑 |
| `VNext` | 长期愿景 | 不作为当前验收依据 |
| `Proposal` | 超出当前 `spec.md` 的设计提案 | 必须先同步产品路线文档，才能实施 |

页面、组件和能力必须显式标注阶段。没有阶段标签的内容默认不得实施。

## 2. 产品气质

XueJian 是本地优先的深度学习工作台：

```text
PDF 资料 -> 阅读沉淀 -> 卡片管理 -> 间隔复习 -> 进度反馈 -> V1 知识问答
```

设计关键词：

- 专业。
- 克制。
- 清晰。
- 高信息密度。
- 长期使用不疲劳。
- 来源可追踪。

禁止把界面做成：

- 营销网站。
- 通用 AI 聊天页。
- 装饰性笔记软件。
- 暗黑开发者控制台。
- 卡片堆叠的信息展板。

## 3. 信息架构

### 3.1 MVP App Shell

`MVP`

```text
App Shell
├── Sidebar
│   ├── 首页 home
│   ├── 文档 library
│   ├── 卡片 cards
│   ├── 学习 learning
│   └── 设置 settings
├── Main
│   └── 当前页面
└── Global Layers
    ├── Toast
    ├── Dialog / Drawer
    ├── Tooltip / Popover
    └── Background Job Status
```

规则：

- Sidebar 桌面端常驻，窄屏进入顶部或底部紧凑导航。
- Reader 打开时隐藏主 Sidebar。
- Reader 不是主导航项。
- 当前页面必须有明确导航上下文。
- 冻结功能不得出现在 MVP 主导航。

### 3.2 V1 导航扩展

`V1 / Proposal`

V1 可新增 `知识/RAG` 主导航：

```text
首页 / 文档 / 卡片 / 学习 / 知识 / 设置
```

约束：

- 若 `spec.md` 未同步该路线，`知识/RAG` 入口标为 `Proposal`。
- 知识页是学习型问答，不是通用聊天。
- 知识页不替代 Reader，也不负责自动制卡。

### 3.3 VNext / Proposal 能力

以下能力可以记录为设计探索，但不得进入当前验收：

- `VNext` 多标签 Reader。
- `VNext` 导出中心。
- `VNext` 同步状态。
- `Proposal` 播客脚本和音频工作台。
- `Proposal` 插件式导航。
- `Proposal` 个性化积分或成就页。

## 4. 主题系统

### 4.1 主题模型

`MVP 文档契约 / 后续代码实施`

```text
theme = light | dark | system
```

- `light`：默认浅色主题，暖纸张、低对比、阅读友好。
- `dark`：深色主题，一等主题，不是浅色反色。
- `system`：跟随 OS 偏好，实际渲染解析为 light 或 dark。

后续代码改造时应把当前 `default` 主题迁移为上述模型；本文档不直接修改 schema 或数据库契约。

### 4.2 语义 token

所有主题都必须提供同名语义 token：

| Token | 用途 |
|-------|------|
| `surface-app` | 应用背景 |
| `surface-sidebar` | Sidebar 背景 |
| `surface-toolbar` | 工具栏背景 |
| `surface-card` | 内容面、卡片 |
| `surface-elevated` | Dialog、Popover、Dropdown |
| `surface-reader` | Reader 阅读背景 |
| `surface-reader-page` | PDF 页面背景或文档面 |
| `text-primary` | 主文本 |
| `text-secondary` | 次文本 |
| `text-tertiary` | 占位符、弱元信息 |
| `text-inverse` | 反色文本 |
| `border-default` | 默认边框 |
| `border-subtle` | 弱分隔 |
| `accent-primary` | 主行动和当前状态 |
| `accent-success` | 成功、掌握 |
| `accent-warning` | 待处理、风险 |
| `accent-danger` | 错误、删除 |
| `accent-info` | 信息、链接、引用 |

### 4.3 Light 色彩方向

`MVP`

- 应用背景：暖纸张，不用纯白。
- 内容面：接近白纸，但用边框分层。
- Reader：暖纸色，优先降低长时间阅读疲劳。
- 强调色：琥珀或橄榄，不常驻大面积高饱和。
- 引用和链接：柔蓝。
- 错误和风险：低饱和玫瑰/红，配合图标和文案。

### 4.4 Dark 色彩方向

`V1`

- 应用背景：低亮度中性深色。
- 内容面：通过轻微亮度差和边框分层。
- Reader：深色阅读背景不能纯黑，避免高对比眩光。
- 强调色：沿用琥珀，但降低饱和和面积。
- 禁止把所有控件做成高亮蓝色开发者工具风。

### 4.5 数据和状态色

热力图固定不超过 5 档：

```text
0 / 1-2 / 3-5 / 6-10 / 10+
```

复习反馈四档：

| 反馈 | 语义 | 颜色方向 |
|------|------|----------|
| 忘记 | again | danger |
| 模糊 | hard | warning |
| 记得 | good | success |
| 熟练 | easy | info |

状态不得只依赖颜色，必须配合文字或图标。

## 5. 基础组件

### 5.1 Button

`MVP`

变体：

- `primary`：当前区域唯一主行动。
- `secondary`：次要行动。
- `ghost`：工具栏或低层级操作。
- `danger`：删除、清空、取消任务等高风险操作。

状态：

- default。
- hover。
- active。
- loading。
- disabled。

要求：

- loading 禁止重复提交。
- danger 必须配合确认或明确影响说明。
- 文案短且直接，不解释功能原理。

### 5.2 IconButton

`MVP`

用途：

- 返回。
- 翻页。
- 缩放。
- 删除。
- 设置。
- 侧栏切换。
- 更多操作。

要求：

- 固定尺寸，标准 32px，紧凑 28px。
- 使用 lucide-react。
- 必须有 `aria-label` 或 Tooltip。
- Tooltip 可显示快捷键。

### 5.3 Tooltip

`MVP`

- 图标按钮必须提供 Tooltip 或等价可访问说明。
- 触发延迟约 300-500ms。
- 内容不超过 60 个字符。
- 快捷键显示在右侧弱文本中。
- 不承载错误详情和复杂说明。

### 5.4 Dialog

`MVP`

用途：

- 删除确认。
- 卡片编辑。
- 设置关键配置。
- 失败详情。

结构：

```text
标题
说明或表单
操作区：取消 + 确认
```

要求：

- 打开时聚焦第一个可交互元素。
- 关闭后焦点返回触发元素。
- Esc 可关闭，危险操作可禁用遮罩关闭。
- 删除确认必须说明影响范围。

### 5.5 Drawer

`MVP`

用途：

- Reader 侧栏窄屏形态。
- 导入队列。
- 高级筛选。
- 任务详情。

尺寸：

- 标准宽度 320px。
- 宽面板 480px。
- 窄屏全宽或接近全宽。

### 5.6 Tabs

`MVP`

- 用于设置页同级分区。
- 不用于主导航。
- 激活态必须明确。
- tab 数量超出容器时允许横向滚动。

### 5.7 Input / Search / Filter

`MVP`

Input：

- 有 label 或 `aria-label`。
- 错误信息靠近输入框。
- 禁用态不可误认为可编辑。

Search：

- 输入 300ms debounce。
- 提供清除按钮。
- 支持 `Ctrl/Cmd + K` 的全局搜索可作为 V1。

Filter：

- 选中筛选以胶囊标签展示。
- 高级筛选进入 Drawer。
- 清除筛选必须可一键完成。

### 5.8 List / Table

`MVP`

列表项必须支持：

- default。
- hover。
- selected。
- loading。
- empty。
- error。

文档列表展示：

- 标题。
- 页数。
- 解析状态。
- 最近阅读时间。
- 卡片数量。
- 主要操作。

卡片列表展示：

- 正面摘要。
- 背面摘要。
- 来源文档。
- 页码。
- 分组或标签。
- 下次复习时间。
- 操作。

### 5.9 Toast

`MVP`

- 右下角或全局反馈层展示。
- 最多同时 3 条。
- 成功 3s，错误 5s，错误允许手动关闭。
- Toast 不承载复杂错误说明；复杂错误进入详情 Dialog 或任务面板。

### 5.10 Skeleton / Empty / Error

`MVP`

Skeleton：

- 模拟真实布局。
- 不使用夸张 shimmer。

Empty：

- 说明当前为空。
- 给出下一步行动。
- 图标轻量，不用大插画抢占。

Error：

- 标题说明错误类型。
- 描述使用用户可理解语言。
- 提供重试、重新配置或查看详情。

## 6. 业务组件

### 6.1 Card Preview

`MVP`

结构：

```text
正面摘要
背面摘要
来源文档 / 页码 / 标签
下次复习时间
操作：编辑 / 删除 / 跳转来源
```

规则：

- 列表中优先紧凑。
- 网格中可展示更多内容。
- 长文本最多 2-3 行截断。
- 来源信息弱层级但必须可见。

### 6.2 Source Quote Block

`MVP`

用途：

- 展示卡片关联原文片段。
- 展示 RAG 引用片段。

结构：

```text
P.12
原文片段...
操作：打开来源 / 展开
```

规则：

- 左侧可用 2px 强调线。
- 过长内容折叠。
- 不允许模型生成的引用伪装成真实来源。
- RAG V1 只展示页码和片段，不承诺 Reader 跳转。

### 6.3 Review Feedback Buttons

`MVP`

布局：

```text
忘记 / 模糊 / 记得 / 熟练
```

要求：

- 等宽排列。
- 支持 `1 / 2 / 3 / 4`。
- 翻面后出现。
- 每个按钮显示中文标签，可在 tooltip 或弱文本展示调度预估。

### 6.4 Background Job Status Badge

`MVP`

状态：

- queued。
- running。
- succeeded。
- failed。
- cancelled。

展示：

- 运行中：任务名 + spinner/progress。
- 成功：短暂提示后消失。
- 失败：可点击查看详情。
- 可取消：显示取消按钮，并二次确认高影响任务。

## 7. 页面规范

### 7.1 Dashboard

`MVP`

目标：回答“今天我该学什么？”。

布局：

```text
今日任务区
学习热力图
最近文档
分组/文档掌握进度
异常提醒
```

必须包含：

- 待复习卡片。
- 新卡待学习。
- 今日完成量。
- 连续学习天数。
- 最近阅读文档。
- 解析失败或复习堆积提醒。

首次使用空状态：

- 不显示空白仪表盘。
- 引导导入第一份 PDF。
- 不展示冻结功能入口。

V1：

- 可增加知识/RAG 的弱入口或最近问答摘要，但仅在 `knowledge` 已进入路线后展示。

### 7.2 Library

`MVP`

目标：管理大量 PDF，快速定位、监控状态、进入阅读。

布局：

```text
顶部工具栏：搜索 + 导入 + 视图切换
筛选栏：状态 + 排序 + 高级筛选
主内容区：列表/网格
底部：分页或加载更多
```

文档状态：

- 未解析。
- 解析中。
- 解析失败。
- 已就绪。
- embedding 缺失或过期（V1 RAG 使用）。

导入流程：

1. 点击导入或拖放 PDF。
2. 显示导入队列。
3. 展示文件名、阶段、进度。
4. 完成后可进入解析。
5. 失败时展示原因和重试。

### 7.3 Reader

`MVP`

目标：让用户在阅读时始终知道当前读到哪里、当前页有哪些卡片、如何快速制卡。

布局：

```text
顶部工具栏
PDF 阅读区
右侧当前页卡片侧栏
```

工具栏：

- 返回。
- 文档标题。
- 页码输入。
- 上一页/下一页。
- 缩放。
- 适应宽度/页面。
- 高亮工具。
- 选区制卡。
- AI 生成卡片。
- 侧栏切换。

右侧卡片侧栏：

- 标题：当前页面卡片（N）。
- Card Preview 列表。
- 空状态：当前页暂无卡片，选中文字即可创建。
- 操作：查看全部卡片。

交互：

- 点击卡片来源可定位到对应页。
- 反向高亮可显示已有卡片数量。
- MVP 不要求精确词级坐标。

VNext / Proposal：

- 多标签 Reader。
- 多文档并排阅读。
- 跨文档引用对照。

### 7.4 Cards

`MVP`

目标：长期维护学习资产，支持检索、批量管理、溯源。

布局：

```text
搜索 + 创建卡片
筛选：文档 / 分组 / 标签 / 复习状态
列表或网格
批量操作栏
```

必须支持：

- Basic 卡片列表。
- 搜索。
- 文档筛选。
- 分组筛选。
- 标签筛选。
- 新增、编辑、删除。
- 多选和批量删除。
- 来源 quote。

批量操作：

- 选中 2+ 项显示固定工具条。
- 工具条包括已选数量、移动分组、删除、取消选择。
- `导出` 属于 VNext/Proposal，不进入 MVP 工具条。

### 7.5 Review

`MVP`

目标：低干扰、高专注、流畅复习。

布局：

```text
顶部进度条
中央卡片
底部反馈按钮组
```

流程：

1. 显示正面。
2. 空格或点击翻面。
3. 显示背面和来源 quote。
4. 选择四档反馈。
5. 进入下一张。

要求：

- 退出时保存进度。
- 进行中退出需要确认。
- 不展示过多统计面板。
- 窄屏下反馈按钮可以纵向排列。

### 7.6 Settings

`MVP`

tab：

```text
AI / 学习 / 通用
```

AI：

- Provider 列表。
- API Key 状态。
- 默认 Provider。
- 测试连接。

学习：

- 每日新卡上限。
- 每日复习上限。
- 复习偏好。

通用：

- 本地数据目录。
- 主题：light / dark / system。
- 应用行为偏好。

不显示：

- podcast。
- points。
- animation。
- export。

### 7.7 Knowledge / RAG

`V1 / Proposal until spec sync`

目标：提供学习型 RAG 问答，只基于用户已导入、已解析并已向量化的文档回答。

布局：

```text
左侧：文档范围和向量状态
中间：问题输入与回答
右侧或下方：引用来源
```

必须包含：

- 可用文档列表。
- 已选文档。
- 向量状态。
- 问题输入。
- 提交按钮。
- 取消按钮。
- 结构化回答。
- 引用卡片。

文档状态：

- ready：可问答。
- embedding_missing：不可提交，引导生成向量。
- embedding_stale：不可提交或要求更新向量。
- embedding_failed：展示失败原因和重试。
- no_documents：引导先导入并向量化文档。

回答状态：

- idle：显示引导和示例问题。
- pending：显示检索和生成阶段，不展示虚假答案。
- answered：展示结构化回答和引用。
- no_relevant_content：明确说明资料中没有足够依据。
- error：展示 provider、timeout、invalid JSON 等可读错误。
- cancelled：停止 pending，显示已取消。

引用格式：

```text
P.12
相关内容片段...
```

V1 不做：

- Reader 跳转。
- PDF 高亮。
- 自动生成卡片。
- 推荐追问。
- 开放域知识补全。

## 8. 状态矩阵

| 页面 | Empty | Loading | Success | Error | Cancelled |
|------|-------|---------|---------|-------|-----------|
| Dashboard | 首次导入引导 | 统计骨架 | 学习概览 | 统计加载失败 | 不适用 |
| Library | 文档库为空 | 文档列表骨架 | 文档列表 | 导入/解析失败 | 导入取消 |
| Reader | 无文档 | PDF 骨架 | 正常阅读 | PDF 损坏/路径失效 | 不适用 |
| Cards | 卡片库为空 | 卡片骨架 | 卡片列表 | 加载/保存失败 | 批量操作取消 |
| Review | 今日无任务 | 队列加载 | 复习中/完成 | 队列失败 | 退出/暂停 |
| Settings | 不适用 | 设置加载 | 设置表单 | 保存失败 | 不适用 |
| Knowledge | 无可用文档 | 问答 pending | 回答和引用 | RAG 失败 | 取消问答 |

## 9. 响应式策略

断点：

- `sm`：640px。
- `md`：768px。
- `lg`：1024px。
- `xl`：1280px。

规则：

- 桌面优先。
- Reader 在 `<1024px` 时右侧栏变 Drawer。
- 表格和热力图窄屏允许横向滚动。
- 复习页保持中央卡片优先。
- 按钮文字过长时换行或改图标+tooltip，不得溢出。

## 10. A11y

全局快捷键：

- `Ctrl/Cmd + K`：全局搜索（V1）。
- `Ctrl/Cmd + 1-5`：切换 MVP 主页面。
- `Ctrl/Cmd + ,`：设置。
- `Esc`：关闭 Dialog/Drawer 或取消当前操作。

Reader 快捷键：

- `PageUp / PageDown`：翻页。
- `Ctrl + +/-/0`：缩放。
- `H`：高亮工具。
- `C`：选区制卡。

Review 快捷键：

- `Space`：翻面。
- `1 / 2 / 3 / 4`：四档反馈。
- `Esc`：暂停或退出确认。

ARIA：

- Sidebar 使用 `nav`。
- 主内容使用 `main`。
- PDF 区域使用 `role="document"` 或等价语义。
- 复习反馈组使用 `role="group"`。
- 进度条使用 `role="progressbar"`。
- Toast 成功/信息使用 `role="status"`，紧急错误使用 `role="alert"`。

## 11. 性能预算

- App 初始可交互目标：2s 内。
- 页面切换目标：200ms 内完成主要布局反馈。
- Reader 翻页交互响应：100ms 内给出反馈。
- 卡片列表搜索 debounce：300ms。
- 长任务必须在 500ms 内显示 pending 或 queued 状态。
- Reader 不因右侧栏内容变化导致 PDF 页面横向跳动。

## 12. 禁止清单

| 禁止项 | 原因 | 替代方案 |
|--------|------|----------|
| 营销 hero | 偏离学习工具 | 首页直接展示今日任务 |
| Reader 主导航 | 打断文档入口模型 | 从文档/卡片来源进入 |

| 大面积渐变和玻璃态 | 噪音过高 | 低对比背景和边界 |
| 纯颜色表达状态 | A11y 风险 | 颜色 + 图标 + 文案 |
| VNext 写成当前任务 | 范围失控 | 标注阶段和 Proposal |
| RAG V1 Reader 跳转 | 与 M14 冲突 | 只展示页码和片段 |
| 导出进入 MVP 卡片工具条 | 冻结功能污染 | 标为 VNext/Proposal |

| IndexedDB 作为新数据权威 | 架构冲突 | 通过 Tauri gateway/SQLite |
