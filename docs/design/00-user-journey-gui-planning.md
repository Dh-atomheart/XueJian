# 前端用户旅程与页面规划

## 核心旅程

1. 新用户完成 AI/BYOK 配置后，进入首页，再从文档库导入第一份资料。
2. 用户从文档库进入 Reader，完成阅读、标注与上下文加工。
3. 用户从文档或 Reader 进入卡片工坊，生成并审核候选卡片。
4. 用户进入学习页完成当日复习，再回到首页或“我的”查看结果。

## 页面关系

- 首页：今日任务与高频入口
- 文档库：资料总入口与详情面板
- Reader：深度阅读与上下文动作
- 卡片工坊：候选卡片生成、审核、入库
- 学习：复习会话与完成页
- 知识问答：可追溯问答与来源跳转
- 播客工坊：生成、审稿、播放、管理
- 我的：学习概览、热力图、积分台账
- 设置：AI、学习、播客、通用配置

## 全局规则

- 顶层导航始终可达，不因为 AI 未配置而整体锁站。
- AI 未配置时限制的是动作，不是页面访问。
- 任意长任务都必须保留任务记录、阶段反馈与恢复入口。
- 任意跨页跳转都优先保留当前文档上下文。
