# M4 阅读与贴笺模块实施计划

## 模块定位

- `Module ID`: `M4`
- `Stage`: `MVP`
- `Priority`: `P0`
- `Spec Reference`: `spec.md` §2.2.4、§5.1.4、§6.2
- `Depends On`: `M1`、`M2`、`M3`
- `Blocks`: 无

## 交付目标

- 在桌面端阅读壳层中实现 PDF 阅读、贴笺卡、高亮与双向跳转
- 保证默认视觉语言覆盖工具栏、贴笺卡和高亮态
- 让“贴笺式学习体验”成为 MVP 核心差异点

## Done Means

- 用户可以边读 PDF 边查看当前页关联卡片
- 点击卡片可跳转到原文，点击高亮可定位卡片
- 桌面布局采用左侧导航轨、中央阅读区、右侧贴笺栏，不复刻手机底部导航

## 前置条件

- `M2` 已输出稳定的 `DocumentAnchor`
- `M3` 已输出正式 `Card`
- `M1` 已提供默认壳层与主题 primitives

## 交付物

- UI层：PDF 阅读器、工具栏、贴笺侧栏、高亮菜单
- 数据层：高亮与卡片的关联持久化
- 交互层：滚动联动、卡片跳转、高亮编辑
- 测试层：阅读、跳转、缩放映射与视觉验收

## 接口与数据契约

- 公共业务类型：`Highlight`、`DocumentAnchor`、`Card`
- 关键契约：
  - `Highlight.cardId` 指向正式卡片
  - 当前页筛选以 `pageNumber/sourcePage` 为主，锚点为辅
  - UI 必须在阅读区和贴笺栏之间保持同一视觉系统
- 模块内部实施类型：
  - `ViewerPageState`
  - `StickyNoteViewModel`

## 数据流 / 交互流

1. 打开文档并加载当前页
2. 读取页码对应卡片与高亮
3. 侧栏显示贴笺卡并按段落排序
4. 点击卡片跳到原文；点击高亮打开贴笺卡
5. 选中文本后可创建高亮或卡片

## 异常与边界

- 贴笺与高亮的装饰线不得影响文本选择、滚动或点击热区
- 高亮颜色体系必须克制，避免破坏默认纸感界面
- 若锚点定位失败，需提供手动重新绑定入口

## 测试矩阵

- 单元：页码过滤、坐标计算、卡片排序、高亮编辑
- 集成：滚动联动、点击跳转、从 PDF 创建卡片
- 视觉验收：桌面壳层一致、贴笺卡视觉统一、高亮不遮挡文字
