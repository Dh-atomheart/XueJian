# Design Tokens 与视觉契约

## 1. 来源与使用边界

当前实现锚点为 `xuejian/src/design-system/tokens.ts`。本文件不扩展运行时代码接口，但把既有 Token 的职责、适用范围和禁用边界写清楚，供后续实现遵循。

## 2. ThemeTokens

## 2.1 Colors

| Token | 当前值 | 职责 | 使用边界 |
|------|------|------|------|
| `paperBase` | `#fbfbf9` | 全局纸感底色 | 用于应用主背景和阅读环境，不用于强交互态 |
| `ink` | `#1a1a1a` | 主文字、主边线、主要按钮 | 不用于大面积实心背景 |
| `inkMuted` | `#666666` | 次级说明文字 | 不用于核心操作文本 |
| `inkSoft` | `#a0a0a0` | 弱提示、占位、非关键元信息 | 不用于可交互正文 |
| `lineSoft` | `#e5e5e0` | 分隔线、弱边框 | 不承担层级强调任务 |
| `highlight.yellow` | `#F8E16C` | 贴笺、标注、轻提醒 | 保持低面积使用，避免整屏高亮 |
| `highlight.green` | `#C8E6C9` | 成功、可继续、学习反馈 | 只作强调，不做大片背景 |
| `highlight.blue` | `#BBDEFB` | 信息性定位、阅读联动 | 用于链接原文或工具高亮 |
| `highlight.pink` | `#F8BBD9` | 轻量提醒、待确认事项 | 避免成为默认主色 |

补充规则：

- MVP 默认主题仍以中性色为主，彩色只作为状态强调
- 页面层级优先依赖留白、边线和排版，不依赖重色块

## 2.2 Typography

| Token | 当前值 | 主要职责 | 规范 |
|------|------|------|------|
| `fontDisplay` | `Kose, Xiaolai, serif` | 页面标题、品牌字、章节标题 | 只用于短标题，不用于长段落 |
| `fontUi` | `Yozai, sans-serif` | 导航、按钮、标签、工具栏 | 负责界面秩序和控制感 |
| `fontBody` | `LXGW WenKai, serif` | 正文、说明、卡片内容 | 必须保持最高可读性 |
| `fontLatinMeta` | `Inter, sans-serif` | 英文模型名、数值、技术元数据 | 只用于拉丁字符和混排元信息 |

使用原则：

- 页面标题优先 `fontDisplay`
- 工具和按钮优先 `fontUi`
- 长文本、问题答案、帮助说明优先 `fontBody`
- 模型名、路径、版本、数字统计可使用 `fontLatinMeta`

禁用规则：

- 不使用展示字体渲染卡片正文
- 不使用手写感字体渲染表单和密集元数据

## 2.3 Spacing

| Token | 当前值 | 推荐用途 |
|------|------|------|
| `xs` | `4px` | 图标与文本微距、细小状态徽记 |
| `sm` | `8px` | 控件内部间距、标签间隔 |
| `md` | `16px` | 默认内容间距、卡片内部布局 |
| `lg` | `24px` | 模块间距、页内分区 |
| `xl` | `32px` | 页面主区块分隔 |
| `2xl` | `48px` | 重要首屏留白和大模块开场 |

规则：

- 同一容器内只允许使用 2-3 个相邻尺度，避免节奏混乱
- 阅读页和学习页优先使用 `md`、`lg`、`xl`

## 2.4 Borders

| Token | 当前值 | 职责 |
|------|------|------|
| `hairline` | `0.5px solid` | 顶栏、弱分隔、精细结构线 |
| `thin` | `1px solid` | 面板边框、输入框、按钮轮廓 |
| `sketch` | `2px` | 手绘感强调边界，主要用于风格化组件 |

规则：

- 默认边线使用 `hairline` 或 `thin`
- `sketch` 只用于局部强调，不作为全站默认边线

## 2.5 Shadows

| Token | 当前值 | 使用范围 |
|------|------|------|
| `paper` | `0 1px 3px rgba(0,0,0,0.04), 0 1px 2px rgba(0,0,0,0.02)` | 轻面板、输入框 |
| `sticky` | `0 2px 8px rgba(0,0,0,0.06)` | 贴笺、浮起纸片 |
| `card` | `0 1px 4px rgba(0,0,0,0.05)` | 普通卡片、轻浮层 |

规则：

- 阴影只是区分表面，不承担品牌氛围
- 不允许使用大面积模糊阴影制造悬浮感

## 2.6 Textures

| Token | 当前值 | 用途 | 限制 |
|------|------|------|------|
| `paperGrain` | `/textures/paper-grain.png` | 外层纸感环境 | 低透明度，不进入正文热区 |
| `scribbleOverlay` | `/textures/scribble-overlay.png` | 装饰性弱覆盖 | 仅用于壳层和空状态插图区域 |

## 2.7 Icon Style

`iconStyle = 'hand-drawn-monoline'`

图标规范：

- 单线描边
- 线宽稳定
- 不依赖填充块表达语义
- 保持工具感而非玩具感

## 3. SketchStyle

| 字段 | 当前值 | 说明 |
|------|------|------|
| `lineWeight` | `hairline | thin | medium` | 手绘线条粗细档位 |
| `roughness` | `0.5` | 当前建议保持中低 roughness |
| `underlineStyle` | `pencil | marker` | 标题强调与内容标记方式 |
| `scribbleOpacity` | `0.1` | 涂写层默认极弱透明度 |

适用范围：

- `roughness` 适合标题装饰、卡片外轮廓、轻量标签
- `underlineStyle.pencil` 适合细节提示
- `underlineStyle.marker` 适合章节标题和关键提示

禁用范围：

- 输入框轮廓
- PDF 正文高亮主逻辑
- 设置页表单结构
- 任何要求像素级精确点击的控件

## 4. SurfaceVariant

| Variant | 视觉职责 | 典型容器 | 不适用场景 |
|------|------|------|------|
| `canvas` | 页面主工作区底面 | 首页主区、阅读主区、学习舞台 | 模态、浮层 |
| `panel` | 常规功能面板 | 侧栏、配置区、列表区 | 需要强情绪强调的贴笺 |
| `paperCard` | 中等强调的信息卡 | 文档卡、统计摘要、信息块 | 高干扰告警 |
| `stickyNote` | 上下文贴笺与附着信息 | 阅读页贴笺、注释提示 | 表单主结构、密集列表 |
| `toolbar` | 工具条和页面头部 | `TopBar`、阅读工具栏 | 大面积正文容器 |
| `modal` | 聚焦决策和确认 | 确认弹窗、批量操作浮层 | 常驻页面区域 |

## 5. PageShellVariant

| Variant | 布局特点 | 顶栏密度 | 上下文栏 |
|------|------|------|------|
| `dashboard` | 首屏概览 + 快速动作 | 低 | 默认无 |
| `library` | 筛选、搜索、列表/网格 | 中 | 默认无 |
| `reader` | 工具栏 + PDF 主区 + 贴笺联动 | 中高 | 必需 |
| `review` | 状态条 + 单任务舞台 | 低 | 默认无 |
| `settings` | 分组表单 + 反馈区 | 中 | 默认无 |

## 6. 动效与反馈 Token 级规则

- 页面切换：`120-180ms`，轻微渐入和位移
- 卡片翻面：`180-260ms`，强调节奏但不延迟操作
- 联动高亮：`160-220ms`
- 成功反馈：优先边框、浅色底和文案，不用夸张弹窗

## 7. 响应式尺度

| 视口 | 目标策略 |
|------|------|
| `> 1440px` | 完整桌面，多栏同时存在 |
| `1280px - 1440px` | 保持桌面完整结构，收缩内容间距 |
| `1024px - 1280px` | 隐藏 `ContextRail`，保留核心任务 |
| `< 1024px` | 仅定义最低可用桌面退化，不扩展移动端设计语言 |

## 8. 当前实现与目标规范

- 当前 `tokens.ts` 已提供核心字段和类型定义
- 当前代码尚未完整体现状态色、层级、动效与响应式策略
- 后续新增样式或主题资源时，优先扩展 `tokens.ts`，并同步更新本文件
