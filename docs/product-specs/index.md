# 产品规格索引

## 产品定位

学笺是一个本地优先的桌面学习应用。核心闭环是：

`上传文档 -> 生成卡片 -> 贴笺阅读 -> FSRS 复习 -> 查看反馈`

默认体验以桌面端为中心，强调本地数据控制、BYOK、原文上下文学习和结构化 AI 工作流。

- [v2.md](./v2.md)：知识问答、多格式导入、积分系统
- [v3.md](./v3.md)：动画与播客类长任务

## 通用边界

- 首版不做可视化工作流编排器。
- 首版不做云端账户和多端同步。
- 首版不交付 Android 应用。
- `SQLite` 是主数据真相源，`Stronghold` 是密钥真相源。
- 桌面端默认视觉基线固定为“极简学术感 + 中度手绘漫画风格”。
