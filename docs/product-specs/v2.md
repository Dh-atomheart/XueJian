# V2 规格

## 目标

在不破坏 MVP 学习体验的前提下，扩展知识问答、多格式导入和积分系统。

## In Scope

- 知识库问答（简单 RAG，而非 agentic RAG）
- MD/TXT/DOCX 导入
- 可审计积分系统
- 可追溯引用

## Done Means

- 用户可以在指定知识范围内提问并获得带引用的回答。
- RAG 默认采用 `FTS5 + sqlite-vec` 混合检索；缺 embedding 时可降级。
- 新格式导入后，仍走统一文档 -> 卡片流程。
- 积分系统具备记账、防重与回溯能力。

## 边界

- 不重写 MVP 的数据层与任务边界。
- 不把 RAG 并入通用 agent runtime。
- 不引入云同步作为前提。
