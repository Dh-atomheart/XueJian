# V4 规格

## 目标

提供可信知识图谱、主题扩展能力，并完成 Android 迁移能力评估。

## In Scope

- 知识图谱构建、增量更新、来源回溯
- 主题切换与扩展主题包
- Android 协议复用与迁移评估

## Done Means

- 图谱节点和关系可追溯到来源材料。
- 主题切换不破坏核心阅读和学习体验。
- Android 评估输出明确的能力矩阵、阻塞项和建议优先级。

## 边界

- Android 评估不等于正式 Android 上线。
- 不为跨端复用强行绑定与桌面完全相同的进程拓扑。
