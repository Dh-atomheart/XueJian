# MVP 规格

## 目标

MVP 的目标是完整打通本地学习闭环，让用户能够从 PDF 开始，完成卡片生成、确认、阅读联动与一次真实复习流程。

## In Scope

- PDF 文档上传与解析
- 文档锚点与原文定位
- LLM 卡片候选生成与人工确认
- 正式卡片 CRUD 与导出
- 阅读页原文/卡片双向联动
- FSRS 学习调度与基础学习反馈
- BYOK 模型配置、连接测试和本地密钥存储
- 长任务的最小恢复能力

## Done Means

- 用户上传 PDF 后可以生成、确认并保存卡片。
- 卡片能够在阅读页与原文双向联动。
- 用户可以完成一轮 `Again / Hard / Good / Easy` 评分流程。
- 所有核心业务数据落在 `SQLite`，密钥落在 `Stronghold`。
- 卡片生成类长任务可恢复，且不会产生重复正式卡片。
- 首页、阅读页、学习页、设置页共享统一的桌面视觉基线。

## 非目标

- 不做 RAG 问答。
- 不做 MD/TXT/DOCX 导入。
- 不做播客和动画生成。
- 不做知识图谱。
- 不做正式移动端交付。

## 验收重点

- 上传、解析、生成、确认、阅读、复习整条链路能跑通。
- 失败状态有可解释反馈，不以静默失败替代。
- UI 不退化成通用后台模板风。
- 默认工作模式始终是桌面多栏布局，而不是移动端单栏心智。
